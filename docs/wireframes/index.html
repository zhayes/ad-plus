Ad+ P0 线框

01–03 是 v2 三屏；04–07 是早期；08 是导航方案；09–13 是模块页。低饱和度与虚线表示占位，文字即规格。
文档：页面规格 v3.3 · 模块与导航 v3.2 · 入口地图 v3 · PRD v2

01 · 项目首页/projects/:id 打开 HTML
播放器 + 版本对比、分镜条、按项目隔离的待办、简报、体检、花费。顶栏不再放模型选择。
02 · 工作台/projects/:id/workspace 打开 HTML
播放器为主角；选中镜头时右侧显示检查器；分镜条可锁定；聊天退为“导演”侧栏。
03 · 审批中心/projects/:id/approvals 打开 HTML
分镜模式：逐镜通过/打回/锁定，概念与交付内容先于价格，档位切换即改价，倒计时前置。
04 · 画布（v3 默认态）一屏三态 打开 HTML
无左栏、无右栏、无模型选择器；常驻只有项目状态、模式开关、一个主操作。对话收成 38px Dock。
05 · 审片（同一画布）Review 态 打开 HTML
不是新页面，是画布的第三个密度：默认全部通过，只标问题镜；一条决策栏完成批准。
06 · 命令面板（入口兜底）⌘K 打开 HTML
一个框搜项目、动作、素材、设置；每个动作带快捷键。没有常驻入口的功能，全部在这里可搜。
07 · 底部模块坞（v3.1 早期，已修正）Bottom dock 打开 HTML
顶栏只剩项目与主操作；模式、模块、状态下沉到底栏；项目面板从左侧空位打开，视频不动。
08 · 底部主模块 + 顶部子 tab（当前）v3.2 打开 HTML
底部 = 项目 / 制作 / 资产 / 任务；顶部 = 当前项目的子 tab（画布 / 分镜 / 审片）+ 唯一主操作。
09 · 项目页v3.3 打开 HTML
作品集：状态筛选、搜索排序、卡片菜单、新建项目；总览用右侧抽屉，不另开页。
10 · 资产页v3.3 打开 HTML
素材 / 品牌 / 模板；类型/来源/项目筛选；右侧详情抽屉；复用规则写清可用条件。
11 · 任务页v3.3 打开 HTML
运行/失败/完成/中断；失败行就地展开错误、重试、日志；费用与列表一致。
12 · 分镜（P0 排序 / 增删）v3.3 打开 HTML
拖拽排序、插入线、添加镜头、单镜重做/锁定；总时长实时校验。批量（多选）为 P1。
13 · 品牌包（P0）v3.3 打开 HTML
品牌列表 + 编辑器 + 品牌检查 + 片头预览；禁用词直接进审片合规。
