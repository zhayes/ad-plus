## 0. 结论

**可以，而且比顶栏更适合 Ad+。** 但要照搬 Zed 的语义，而不是把顶部菜单整体搬到底部：

- Zed 的底栏是**状态栏 + 面板开关**，不是主导航。
- 它把低频工具放在窗口边缘，把中间留给内容。
- Ad+ 的 9:16 画布两侧天然是空的，底部适合放模块与状态；顶部只留项目与主操作。

一句话：**入口下沉到底部，面板就近打开，画布位置不变。**

---

## 1. 为什么参考 Zed 成立

| 维度 | 顶栏放模块 | 底栏放模块 |
|---|---|---|
| Fitts 定律 | 要精确移动到顶部 | 底边是窗口边缘，容易命中 |
| 视觉重心 | 模块与状态占据第一视线 | 第一视线留给视频与主操作 |
| 状态归属 | QA/花费/待办挤在项目旁 | 状态天然属于状态栏 |
| 可发现性 | 常驻、明确 | 常驻 + 标签 + 快捷键，同样明确 |
| 与内容冲突 | 靠近 macOS 标题栏 | 靠近 transport / 胶片，需要严格分层 |

> 真正不适合放底栏的是**主操作**与**播放控制**：前者需要唯一、醒目；后者属于内容，应贴着视频。

## 3. 底栏规格

### 3.1 三个区

| 区 | 内容 | 规则 |
|---|---|---|
| 左 | 模式：画布 / 分镜 / 审片 | 当前态高亮；`⌘1/2/3` |
| 中 | 模块：导演 / 项目 / 素材 / 任务 / 版本 / 设置 | 最多 6 个；图标 + 10px 标签；有 badge |
| 右 | QA·花费 / 待办 / `⋯` | 只读状态；异常变红 |

- 高度 36；单项命中区 ≥28×28。
- 图标 + 短标签；窗口 <1000 时标签收成图标 + tooltip。
- 激活项：底色 + 顶部 2px 主色线；再次点击收起面板。
- 同一时间只开一个面板；`Esc` 关闭；关闭后焦点回到画布。
- 任务有运行时，`任务` 显示数字徽标；审批待办在 `项目` 上显示红点，右侧另有待办药丸。

### 3.2 为什么模式和模块都在底栏

- 模式是“看同一条片子的三种密度”，模块是“离开内容去管理”；两者都是应用层，放在一起符合“底栏是工具架”的语义。
- 顶部只留“我在做什么 + 下一步”，保持单一焦点。

## 4. 面板就近打开（入口在底，面板不必在底）

| 模块 | 面板位置 | 宽度/高度 | 理由 |
|---|---|---|---|
| 项目 | 左抽屉 | 300 | 利用画布左侧空位，不遮视频 |
| 素材 | 左抽屉 | 320 | 网格/列表，可拖到画布 |
| 版本 | 左抽屉 | 300 | 列表 + 对比 |
| 导演（对话） | 左抽屉 | 420 | 长对话需要宽度；不遮视频 |
| 任务 / 日志 | 底部短抽屉 | 220–260 | 短列表，不占画面中心 |
| 设置 | 模态 | 720×560 | 配置是打断式任务 |
| 导出 | 模态 / 右下浮层 | — | 一次性决定 |
| QA / 花费 | 底栏上方 popover | — | 只读详情 |
| 审片 | 全画布态 | — | 需要最大分镜面积 |

规则：
- **面板不改变画布尺寸，也不移动视频。** 左抽屉只覆盖空侧；底部抽屉只覆盖画面下缘。
- 在 1440 宽下，300/420 的左抽屉与 360 宽的视频之间仍有 120–240px 间距。
- 窗口 <1280 时，抽屉宽度降到 280/360；<1100 时允许覆盖视频边缘，但可一键收起。
- 底部抽屉打开时，胶片条暂时隐藏；关闭后恢复，避免两层底部元素叠加。

---

## 5. 垂直层级（防止底部堆叠）

同一时间最多两层：

```
视频
  └ transport（28px，叠在视频下方）
      └ 胶片条（仅分镜态，96px，可折叠）
          └ 底部抽屉（仅打开时，220–260px，覆盖）
              └ 底栏（36px，固定）
```

- 画布态：视频 + transport + 底栏。
- 分镜态：视频 + transport + 胶片条 + 底栏。
- 任务抽屉打开：底栏 + 抽屉；胶片条隐藏。
- 审片态：全画布分镜 + 决策条；底栏仍在，但不显示胶片。

| 元素 | v3 | v3.1 |
|---|---|---|
| 模式开关 | 顶栏居中 | 底栏最左 |

**顶部只保留：** 项目 chip（当前项目 + 状态）、一个主操作。

## 7. 代价与对策

| 代价 | 对策 |
|---|---|
| 底栏可能变成第二导航 | 最多 6 个模块，不做二级菜单；溢出进 `⋯` / `⌘K` |
| 图标歧义 | 图标 + 标签；tooltip 带快捷键；首次引导 |
| 底部元素堆叠 | 严格垂直层级；同一时间最多两层 |
| 模式在底部不习惯 | 左起第一组、带文字；`⌘1/2/3`；首次 3 秒提示 |
| 对话输入不再常驻 | `⌘J` 一键；`导演` 抽屉打开即聚焦输入框 |
| macOS Dock 干扰 | 底栏内边距 12px；全屏下无影响 |
| 小窗口拥挤 | <1000 标签收成图标；<1280 抽屉变窄 |

> 如果上线后发现“问导演”频率远高于预期，再在底栏上方加一条 32px 的快捷输入（仅编辑态），而不是恢复常驻侧栏。

## 8. 交互与快捷键

- `⌘1 / ⌘2 / ⌘3`：画布 / 分镜 / 审片。
- `⌘J`：导演抽屉（再按收起，焦点回画布）。
- `⌘O`：项目抽屉；`⌘,` 设置；`⌘K` 命令面板。
- `Esc`：关闭当前面板；若没有面板，退出审片。
- 模块不设单键快捷键，避免和模式/播放键冲突；全部可由 `⌘K` 搜到。
- 抽屉打开时，画布仍可播放（左抽屉不遮挡视频）；底部抽屉打开时暂停播放。

## 9. 验收

1. 1440 / 1180 / 960 三档宽度下，底栏不溢出；<1000 标签收起。
2. 底栏高度 36；1440 下视频 ≥360×640。
3. 点 `项目 / 素材 / 版本 / 导演` 打开左抽屉，视频位置与尺寸不变。
4. 点 `任务` 打开底部抽屉，胶片条隐藏；关闭后恢复。
5. 同一时间只有一个面板；`Esc` 关闭；激活态与徽标正确。
6. 底栏所有模块动作都能在 `⌘K` 与原生菜单找到。
7. QA / 花费 / 待办可见；`fail` 时变红并锁住主操作。
8. 对话抽屉打开后输入框自动聚焦，`⌘J` 可收起。

## 10. 一句话

**顶栏只回答“我在做什么、下一步是什么”，底栏回答“还有哪些工具、现在什么状态”；面板从空位移出，画布不动。**
