## 0. 通用规则

### 0.1 页面类型

| 类型 | 用在哪 | 规则 |
|---|---|---|
| **页面** | 4 个主模块 | 全屏；底部模块切换；顶部上下文与子 tab |
| **右侧抽屉** | 项目总览、素材详情、导演对话 | 不跳页；宽度 340–420；`Esc` 关闭 |
| **模态** | 方案闸门、导出、设置、日志 | 一次性决定；关闭后回到原位置 |
| **底部短抽屉** | 任务详情（P1） | 不遮画面中心；与胶片条互斥 |

> 不新增第三级页面。任何“详情”优先用抽屉，任何“决定”优先用模态。
> 右侧同一时间只开一个抽屉（项目总览 / 导演 / 素材详情），打开新的先关旧的。

### 0.2 顶栏

- 左：上下文。制作 = 项目 chip；其他模块 = 模块名 + 数量。
- 中：当前模块的子 tab，**绝对居中**。
- 右：最多一个主操作；没有合适的主操作就留空，不放“刷新”之类的假主操作。
- 高度 44；子 tab 不因左右内容宽度变化而位移。

### 0.3 底栏

- 高度 36；左 4 个主模块；右只读状态 + 设置/帮助。
- 当前模块顶部 2px 主色线；任务有运行/失败时显示数字徽标。
- 底栏不放业务动作、不放模式、不放聊天。

### 0.4 空态 / 加载 / 错误

| 状态 | 规则 |
|---|---|
| 空 | 给“下一步做什么”的入口，不写抒情文案 |
| 加载 | 骨架屏；超过 300ms 必须出现 |
| 无结果 | 显示当前筛选条件 + 一键清除 |
| 错误 | 人话 + 原因 + 重试 + “复制详情”；不显示裸 stack |
| 文件缺失 | 卡片标“文件缺失”，可 Finder 定位或移除 |

### 0.5 响应式

| 宽度 | 项目网格 | 素材网格 | 抽屉 | 顶栏 |
|---|---|---|---|---|
| ≥1280 | 3 列 | 4 列（抽屉开） | 340–420 | 一行 |
| 1024–1279 | 3 列 | 3 列 | 320–360 | 一行 |
| 960–1023 | 2 列 | 2–3 列 | 覆盖式 | 项目标题截断 |

### 0.6 文案

- 动作 = 动词 + 对象：`看方案与报价`、`确认并生成`、`导出成片`、`重做此镜`。
- 状态 = 事实：`方案待确认`、`生成中 62%`、`已交付`。
- 不用“审阅”“提交”“下一步”这类不说明对象的词。

### 1.2 页面结构

```
┌ 项目 8   2 个待办 · 本月 $3.20     [全部 进行中 已交付]        [＋ 新建项目] ┐
│ [搜索项目/品牌/产品] [全部平台] [最近更新]                    [▦ ☰]         │
│ ┌────────────┐ ┌────────────┐ ┌────────────┐                              │
│ │  封面 16:9  │ │  封面       │ │  封面       │   卡片：状态、待办、进度     │
│ │ 状态 时长 ⋯ │ │            │ │            │                              │
│ └────────────┘ └────────────┘ └────────────┘                              │
│  标题           标题           标题                                         │
│  平台·比例·版本  平台·比例·版本  平台·比例·版本            更新时间          │
└────────────────────────────────────────────────────────────────────────────┘
```

### 1.3 卡片字段

| 字段 | 来源 | 展示 |
|---|---|---|
| 封面 | `cover` / 最新版本 poster | 16:9 容器；9:16 成片居中，模糊背景填充，不硬裁 |
| 状态 | `status` | 草稿 / 方案待确认 / 制作中 / 待审片 / 已交付 / 已归档 |
| 待办 | `pending_count` | 左上角“1 待确认”；0 不显示 |
| 进度 | 当前 job | 制作中显示 62% + 底部进度条 |
| 时长/比例 | `duration_s/aspect` | 右下角 `15s`；元信息里 `9:16` |
| 标题 | `title` | 一行截断；副行平台 · 比例 · 版本 |
| 更新时间 | `updated_at` | 右侧相对时间（2 分钟前/昨天/11月3日） |

### 1.4 交互

- **点击卡片** → 制作·画布（打开该项目，保留上次子 tab）。
- **卡片 ⋯** → 菜单：打开制作 / 项目总览 / 复制 / 归档 / 删除 / 在 Finder 显示。
- **删除**：二次确认 → 废纸篓；10 秒内可撤销；不物理删除。
- **归档**：从进行中列表移出；不删文件；可在“显示已归档”找回。
- **搜索**：匹配标题、产品、品牌；无结果给“清除筛选”。
- **筛选/排序**：切模块再回来保持状态。
- **新建项目**：打开起始卡（模态），不跳页。

### 1.5 新建项目起始卡

| 字段 | 必填 | 默认 | 控件 |
|---|---|---|---|
| 一句话描述 | 是 | — | 多行输入；占位“卖什么、给谁、什么感觉” |
| 平台 | 是 | 抖音 | 平台卡（抖音/小红书/视频号/Shorts/其他） |
| 时长 | 是 | 15s | 6/15/30/60 分段 |
| 比例 | 否 | 由平台推导 | 9:16/4:5/1:1/16:9 |
| 模板 | 否 | 无 | “从模板”入口 |
| 素材 | 否 | 无 | “导入素材/参考” |

- 主操作：`开始做方案`；次操作：`从模板开始`、`导入素材`。
- 提交后：创建项目 → 进入制作 → 方案生成中；成功后主操作变 `看方案与报价`。
- 不强制填满：除一句话外都可默认。

### 1.6 项目总览（右侧抽屉 420）

| 区块 | 内容 | 操作 |
|---|---|---|
| 头部 | 标题、状态、平台/比例/时长/档位 | 重命名 |
| 简报 | 产品、人群、卖点、CTA、调性、禁用词 | 编辑（侧滑表单） |
| 方案记录 | 每次 quote：概念、价格、结果、时间 | 查看详情 |
| 版本 | V1…Vn，当前版本、花费 | 切换/对比/回滚/导出 |
| 交付 | 导出文件、封面、SRT、大小 | 下载/Finder/删除 |
| 花费 | 已花/预算、按版本/按工具 | 查看明细 |
| 项目设置 | 平台/比例/时长/档位、复制、归档、删除 | 二次确认 |

### 1.7 状态

- **空**：一句话输入卡 + 3 个模板 + “导入素材”；不显示空白网格。
- **无结果**：显示“没有匹配「xxx」的项目”+ 清除。
- **加载**：6 个卡片骨架。
- **损坏**：卡片标“无法读取”，提供 Finder 定位/移除。
- **首次**：空态兼引导，不再单独做 onboarding 项目页。

### 1.8 验收

1. 新建项目到“方案生成中” ≤2 次操作。
2. 卡片点击进入正确项目；返回后筛选/搜索/滚动保持。
3. 删除可撤销；归档可找回。
4. 总览抽屉包含简报/方案/版本/交付/花费。
5. 3/2 列响应式；无横向滚动。
6. 空态、无结果、加载、损坏四态齐全。

## 2. 制作

### 2.1 功能清单

| 功能 | P | 说明 |
|---|---|---|
| 画布播放/选镜 | P0 | 播放、逐帧、选中镜头、检查器 |
| 逐镜返工 | P0 | 只重做选中镜；其余锁定 |
| 分镜网格 / 逐镜返工 | P0 | 查看、选中、重做、锁定 |
| 分镜编排 | P0 | 拖拽排序、增删镜头、逐镜描述编辑 |
| 分镜批量 | P1 | 多选、批量生成/锁定/删除 |
| 审片 | P0 | 默认全通过、标问题、QA、确认 |
| 方案闸门 | P0 | 概念 + 3 帧 + 档位 + 价格 |
| 导演对话 | P0 | 右侧抽屉 `⌘J` |
| 版本 | P0 | 切换/回滚；对比 P1 |
| 导出 | P0 | 预设、封面、SRT |
| 字幕/配音/配乐编辑 | P1 | 逐镜文本、TTS 音色、音乐 |
| 撤销/重做 | P1 | 镜头级操作 |

### 2.2 画布（默认子 tab）

```
顶栏：项目 chip · 状态 · V3      [画布 分镜 审片]       [看方案与报价 →]
┌──────────────────────────────────────────────────────────────┐
│                     ┌──────────────┐   ┌ 镜头检查器 ┐        │
│                     │  9:16 视频    │   │ s3 · 5.0–9.5s│        │
│                     │              │   │ 画面/运镜/转场│        │
│                     └──────────────┘   │ 重做 / 锁定   │        │
│                        ▶ 0:03/0:15 ───●──                    │
│  ┌──┐┌──┐┌──┐┌──┐┌──┐  胶片条（5 镜，锁/状态/时长）           │
│  └──┘└──┘└──┘└──┘└──┘                                        │
│                                            ✦ 导演 ⌘J          │
└──────────────────────────────────────────────────────────────┘
```

| 区域 | 字段/交互 |
|---|---|
| 视频 | 9:16，最大 360×640；空格播放；`←/→` ±1s；点击暂停 |
| transport | 播放/暂停、时间、拖动、音量、字幕开关、倍速 |
| 胶片条 | 每镜缩略图、时长、锁、状态；点击选中；双击定位；`[`/`]` 切换 |
| 检查器 | 选中镜的 role/时间/描述/画面/运镜/转场/字幕/台词/成本/重做/锁定/打回 |
| 主操作 | 按状态：开始做方案 / 看方案与报价 / 生成中 / 审片 / 导出 |
| 导演 | 右侧 360 抽屉；`⌘J`；打开即聚焦输入 |

- 未选镜时检查器隐藏，画面保持干净。
- 选中镜的检查器浮在视频右侧空白处，不推挤视频。
- 重做：自动锁定其余镜头；生成 V4；只改一镜。

### 2.3 分镜（子 tab）

> P0 即支持拖拽排序、增删镜头、逐镜描述；批量选择与批量操作为 P1（见 [12 线框](wireframes/12-storyboard.html)）。

- 3×2 网格；每卡：关键帧、编号、role、起止时间、画面描述、状态、锁、⋯。
- 拖拽排序；拖动时显示插入线；松手后重算时间轴。
- 末尾“添加镜头”：从空镜/素材/复制现有镜。
- 镜头菜单：重做 / 锁定 / 打回 / 复制 / 删除 / 导出该镜。
- 多选（P1）：批量生成、批量锁定、批量删除。
- 时间轴总长实时显示；改动超过目标时长时标黄。

### 2.4 审片（子 tab）

- 分镜网格 + 右侧审片栏 + 底部决策条（见 [05 线框](wireframes/05-review.html)）。
- **默认全部通过**；点某镜取消勾选 = 标记问题；备注三行：问题类型 / 一句话 / 只改此镜。
- QA：总时长、字幕安全区、合规用语、比例；音频生成后检查。
- 决策条：
  - 全部通过：`确认并生成`（一个主操作）。
  - 有问题：`确认 4 镜并生成` + “s3 返工后再生成”。
  - QA `fail`：主操作变 `修复并继续`；不允许静默跳过。
- 通过后写审批记录（绑定版本），生成只跑未锁定镜头。

### 2.5 方案闸门（模态 820×600）

| 区 | 内容 |
|---|---|
| 左 | 3 张关键帧 / 分镜节奏条 |
| 右上 | 一句话概念、调性、平台/比例/时长 |
| 右中 | 交付内容：镜头数、尺寸、fps、字幕/配乐/封面 |
| 右下 | 质量档位（草稿/标准/精修）+ 逐项价格 + 总价区间 + ETA + 假设 |
| 底部 | `确认并生成`（主）、`改一下`（次）、`暂不` |

- 档位切换即改价，并显示“免费档是什么样”。
- `改一下` 展开就地 chips：时长/比例/档位/风格/镜头数；不默认给大 textarea。
- 未配媒体 key 时：说明“当前为本地动效档”，给“去配媒体 key”入口。
- 闸门记录 `quote_id + version_id`；确认后不可改历史。

### 2.6 导演对话（右侧抽屉 360）

- 头部：制作记录切换、新记录、模型 chip、关闭。
- 消息：用户/助手、Markdown、工具时间线折叠、审批卡（点开审片）。
- 底部：输入、附件、停止（`⌘.`）、发送（`⌘↵`）。
- 打开时自动聚焦；不 resize 画布；`⌘J` 收起。
- 断线：顶部黄条“已断开，重连中”，输入草稿不丢。

### 2.7 版本与导出

- 版本入口：项目 chip 的版本部分 / 画布右上版本 chip。
- 版本弹层：V1…Vn、当前、花费、时间；操作：设为当前 / 导出 / 回滚 / 对比（P1）。
- 导出模态：平台预设、封面（首帧/自定义/上传）、SRT、文件名模板、导出后打开。
- `⌘E` 用上次预设直接导出；`⌥⌘E` 打开模态。

### 2.8 状态矩阵

| 项目状态 | 主操作 | 画布 | 分镜 | 审片 |
|---|---|---|---|---|
| 草稿/补简报 | 开始做方案 | 起始卡 | 置灰 | 置灰 |
| 方案待确认 | 看方案与报价 | 关键帧/占位 | 置灰 | 置灰 |
| 方案已通过 / 分镜待生成 | 生成 5 镜 | 分镜拼图 | 可编 | 置灰 |
| 生成中 | 生成中 62%（禁用） | 进度 | 可用 | 置灰 |
| 待审片 | 审片 | 成片 | 可用 | 可用 |
| 已交付 | 导出 | 成片 | 可用 | 只读 |

### 2.9 验收

1. 三个子 tab 共享版本、选中镜、时间码。
2. 看方案与报价 → 模态字段齐全；确认后进入生成。
3. 重做一镜只生成一镜，其余锁定；V4 可回 V3。
4. 审片默认全通过；标 1 镜 = 1 次点击；确认 = 1 次点击。
5. QA `fail` 时主操作变“修复并继续”。
6. 导出预设记忆；`⌘E` 可一键。
7. 导演抽屉不改变视频尺寸；`⌘J` 可开合。

### 3.2 素材页

> P0 上线“素材 + 品牌”；模板、音乐库在 P1 出现，不要用空 tab 占位。

- 顶部子 tab：素材 / 品牌 / 模板。
- 工具栏：搜索、类型（全部/图片/视频/音频）、来源（全部/上传/生成/参考）、项目、排序。
- 网格：≥1280 4 列（抽屉开）/ 5 列（抽屉关）；卡片 4:3；类型徽标、时长、名称、来源/大小。
- 空态：上传区 + “从项目导入” + “使用生成物”。
- 上传：显示进度；失败可重试；同名自动加后缀。

### 3.3 素材详情抽屉（340）

| 区 | 内容 |
|---|---|
| 预览 | 9:16/1:1/16:9 自适应；视频可播；音频有波形/播放 |
| 元数据 | 类型、尺寸、时长、大小、来源（上传/生成/参考）、项目、创建时间 |
| 标签 | 自动标签（角色/镜头/风格）+ 手动 |
| 操作 | 用作参考（主）、替换当前镜头（需已选镜）、下载、重命名、Finder、删除 |

- “替换当前镜头”禁用时写明原因：“先在制作里选中一个镜头”。
- 删除：二次确认 + 废纸篓。
- 文件缺失：显示路径与“重新定位”。

### 3.4 品牌页（P0）

- 卡片：logo、名称、主色/辅色、默认徽标、引用项目数。
- 新建/编辑：logo、色板（≤5）、字体、调性、口播人设/音色、禁用词、默认开关。
- 操作：设为默认、应用到当前项目、复制、删除。
- 品牌影响：美术方向、字幕字体、合规禁用词。
- 品牌检查：logo 已上传、主色对比度 AA、字体可用、禁用词条数、口播人设已绑定；不通过只标黄，不阻止生成。
- 保存后同步到引用该品牌的所有项目，下次生成生效；不改历史版本。

### 3.5 模板页（P1）

- 画廊：封面、名称、分类、比例/时长、内置/自建。
- 操作：预览、用它新建项目（起始卡预填）、复制、删除（自建）。
- 内置 5 个：痛点-解法、三条理由、前后对比、UGC 口播、开箱。

### 3.6 状态

- 空：上传区 + 从项目导入。
- 加载：缩略图骨架。
- 上传失败：卡片标错 + 重试。
- 文件缺失：标“文件缺失”+ 定位/移除。
- 存储不足：顶部条提示 + 清理入口。

### 3.7 验收

1. 上传后立即出现缩略图；失败可重试。
2. 四个筛选维度组合正确；搜索 300ms。
3. 详情抽屉不跳页；元数据正确。
4. “替换当前镜头”只在选中镜时可用；禁用有原因。
5. 品牌可应用到项目（P1）；模板可一键新建（P1）。
6. 网格响应式；抽屉开合不横向溢出。

## 4. 任务

### 4.1 功能清单

| 功能 | P | 说明 |
|---|---|---|
| 任务列表 | P0 | 跨项目；运行/失败/完成/中断 |
| 状态筛选 | P0 | 全部 / 运行中 / 失败 |
| 汇总 | P0 | 运行数、失败数、今日花费/预算 |
| 进度 | P0 | 帧/百分比/耗时/当前镜头 |
| 取消 | P0 | 二次确认；停止子进程 |
| 重试 | P0 | 失败/中断；保留原参数 |
| 日志 | P0 | 尾 200 行；复制错误 |
| 自动刷新 | P0 | WS 事件或 2s 轮询；后台暂停 |
| 项目筛选 | P0 | 按项目过滤 |
| 批量重试 | P1 | 多个失败一起 |
| 任务详情页 | P2 | 完整参数/产物/重试历史 |

### 4.2 页面结构

```
┌ 任务 4  1 运行 · 1 失败        [全部 运行中 失败]        [项目全部] [刷新] ┐
│ ┌ 运行中 1 ┐ ┌ 失败 1 ┐ ┌ 今日已花 $0.10 ┐                              │
│ 项目 / 镜头   进度 62%  4.5/7.2s  $0.08  [取消]                          │
│ 项目 / 镜头   失败：音频流缺失 ...  $0.00  [重试][日志]                    │
│   └ 展开：错误原文 + 重试/日志/复制错误 + 输出路径                         │
│ 项目 / 镜头   完成 12.0s  $0.02  [打开成片][Finder]                       │
│ 项目 / 镜头   已中断 · 应用退出  [重试]                                   │
└──────────────────────────────────────────────────────────────────────────┘
```

### 4.3 行规格

| 列 | 内容 |
|---|---|
| 项目/镜头 | 项目 title + 类型（渲染/预览/生成）+ 镜头 id + 版本 |
| 状态/进度 | 运行：进度条 + 百分比 + 帧；失败：错误一句话；完成：耗时/产物数 |
| 耗时 | 已用/预计（运行）；总耗时（完成） |
| 花费 | 单任务成本；失败 $0.00 |
| 操作 | 运行：取消；失败：重试/日志；完成：打开成片/Finder；中断：重试 |

### 4.4 失败展开

- 展开不跳页；显示错误原文（等宽）、发生时间、重试次数、输出路径。
- 按钮：重试 / 打开日志 / 复制错误。
- 日志模态：尾 200 行、复制、打开日志文件。
- 重试沿用原参数；可另存为“重试并改参数”（P1）。

### 4.5 交互与刷新

- 自动刷新：WS 事件优先；无事件时 2s 轮询；页面隐藏时暂停。
- 取消：确认后请求 cancel；状态变“取消中”，进程退出后“已取消”。
- 重试：立即创建新 job，旧 job 保留可追溯。
- 通知点击：打开任务并展开对应行。
- 空态：“没有任务”+“去制作”。

### 4.6 状态

- 运行中、完成、失败、已取消、已中断（应用退出）。
- 后端断开：顶部黄条 + 重试。
- 任务超过 7 天：从列表移除（文件保留），设置里可改。

### 4.7 验收

1. 运行任务进度自动更新，不整页刷新。
2. 失败显示错误原文，重试可成功创建新任务。
3. 取消后进程确实停止。
4. 汇总数字与列表一致（今日花费 = 列表成本之和）。
5. 筛选/项目过滤正确。
6. 日志可打开、复制。
7. 后端断开有明确提示。
