# 复制爆款改编（Director）

输入：`skeleton.json` + `gag_spec.json` + 新产品（图/卖点/价格占位）。
输出：`script.json`（逐 beat 台词）＋ 分镜表（每镜一个动作）。

## 一、台词：先算预算，再写字

中文口播按 **5.5 字/秒** 估时；一个 beat 的台词总时长不得超过该 beat 长度 +0.3s。

| beat 长度 | 可用字数（上限） |
|---|---|
| 1.4s | 7 字 |
| 2.0s | 11 字 |
| 2.5s | 13 字 |
| 3.0s | 16 字 |

规则：

1. **一 beat 一句**，不要跨 beat 写长句；超过预算就删信息，不要加语速。
2. **保留换手节奏**：原片 A 问 B 答就保持 A/B，不要改成单人独白。
3. **保留信息点**：价格出现两次（原价 + 活动价）、一句评价、一句动作词（抢/囤/搬）。
4. **改写只动表面**：商品、数字、措辞、人称可变；机制、顺序、落点时间不可变。
5. 价格一律用占位（如 39.9 / 19.9），并在 `compliance_flags` 里写明“上线前换真实价”。

## 二、分镜：一镜一个动作

镜头数 = beat 数 × 1.2～1.5（多出来的是插入镜头和反应镜头）。

每个镜头写清五件事：

```
主体：谁（同一角色用同一张参考图）
动作：一个动词（走来 / 递袋 / 转身跑出画），不写情绪、不写剧情
景别：特写 / 近景 / 中景 / 全景
机位：固定 / 轻微手持 / 跟拍
商品：在不在画面里、在谁手上
```

硬规则：

- **一镜只写一个动作**。写“吐槽然后抢袋子”必然演砸，拆成两个镜头。
- **中文不进 prompt**：标签、价格、字幕一律写“标签留白”，后期贴真图。
- **首帧必须来自分镜板**（i2v），不要纯 t2v。
- 每个镜头 3 take，选片标准是“动作是否发生”，不是“好不好看”。

## 三、笑点落点

- `gag_spec.timing.punchline_at_s` 对应的那一段，单独成一个镜头，时长给足（≥ 原片该段长度）。
- 落点镜头**不要**配旁白覆盖，让动作和音效说话。
- 如果 3 个 take 都没做出动作，换景别重出（比如从“中景跑出画”改成“手部抓袋 + 脚步”）。

## 四、交付自检

- [ ] 每个 beat 的台词估算时长 ≤ beat 长度 + 0.3s
- [ ] must_keep 每条都能映射到某个镜头或某句台词
- [ ] 落点镜头单独存在，且时长不少于原片
- [ ] 没有任何中文文字进 prompt
- [ ] 价格/功效都有 compliance_flags

## 常见错误

| 错误 | 后果 |
|---|---|
| 按“好看”写分镜，不按动作写 | 模型演不出来，take 全废 |
| 一句台词塞两个信息 | 语速被拉快，节奏失真 |
| 让模型写“原味鹰嘴豆”五个字 | 出来是乱码，必翻车 |
| 整条一次生成 | 喜剧演成证件照 |
| 落点加旁白 | 笑点被解说掉 |
